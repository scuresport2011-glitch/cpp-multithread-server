# C++ Multithread Server

Простой многопоточный сервер, написанный на языке C++. Проект создан для изучения работы сокетов, сетевых протоколов и параллельного программирования (многопоточности).

## Что делает этот проект

* **Принимает подключения:** Сервер слушает определенный порт и готов обрабатывать запросы от клиентов.
* **Работает в несколько потоков:** Использует многопоточность, чтобы обслуживать сразу несколько пользователей одновременно, не заставляя их ждать друг друга.
* **Написан на C++:** Использует стандартные возможности языка для работы с сетью и потоками.

## 🛠 Как собрать и запустить

Для сборки проекта вам понадобятся компилятор C++ и утилита CMake.

Выполните команды в терминале:

```bash
# Сборка проекта
mkdir build
cd build
cmake ..
cmake --build .

# Запуск сервера
./cpp_multithread_server
```
